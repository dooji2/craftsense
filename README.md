# CraftSense

A Minecraft mod that's like autocomplete for the crafting table! You don't need to place every ingredient yourself. If it suggests the recipe you want, just take it from the output slot like you normally would (and yes, shift click works too!).

Categories are generated every time you launch the game, and the mod tracks what you craft in each one. It uses those habits to choose what to suggest, and having many specific categories should make those suggestions pretty (hopefully) accurate.
